**1. analyze_listicle(html: &Html) -> AnalysisResult** (per D-12, D-13, D-14)
- Check ID: `"geo-listicle"`
- Detection logic (broad, per D-12):
  a. Heading patterns: Select `h1, h2, h3` elements, get text, check against three case-insensitive regexes:
     - `(?i)\btop\s+\d+\b` (matches "Top 10", "top 5")
     - `(?i)\bbest\s+\d+\b` (matches "Best 10", "best 5")
     - `(?i)\b\d+\s+(?:best|top)\b` (matches "10 Best", "5 Top")
  b. Ordered lists: Check for `<ol>` elements via `Selector::parse("ol")`
  c. Numbered heading sequences: Check H2/H3 text against `(?i)^\d+[\.\)]\s+` (matches "1. Item", "2) Item")
  d. Comparison tables: Check for `<table>` elements that have `<th>` headers AND >= 3 `<tr>` rows
- When ANY pattern detected: `Status::Pass`, message describes which pattern(s) found (e.g., "Listicle format detected: 'Top N' heading pattern"), recommendation is empty string
- When NONE detected: `Status::Warn`, message: "No listicle format detected on this page", recommendation: "Consider restructuring content as a numbered list or 'Top N' format -- 74.2% of AI citations come from listicle-style content. Use ordered lists, 'Top N'/'Best N' headings, or comparison tables to improve AI search visibility"
