Returns exactly 4 results. Per D-12: each check independent.

**geo-query-qa-patterns:** Detect question-then-answer structures.
- Select h2, h3 headings. Check if heading text ends with "?" or matches patterns like "What is", "How to", "Why do", "When should", "Where can".
- Regex for question headings: `r"(?i)^(what|how|why|when|where|who|which|can|does|is|are|should|will)\b.*\??$"`
- Pass if at least 1 question heading found, Warn if none.
- Message pass: format!("{} question-answer heading pattern(s) found.", count). Message warn: "No question-answer heading patterns detected."
- Recommendation: "Structure content with question-phrased headings (H2/H3) followed by direct answers. AI search engines extract Q&A patterns for featured responses."

**geo-query-summary:** Detect TL;DR / key takeaway sections. Per D-14 (covers GEO-05).
- Check for elements with class/id containing "tldr", "summary", "key-takeaway", "takeaway", "overview" (CSS selectors: `[class*="tldr"], [id*="tldr"], [class*="summary"], [class*="takeaway"], [id*="takeaway"]`)
- Also check heading text against regex: `r"(?i)^(tl;?\s*dr|key\s+takeaways?|summary|in\s+brief|at\s+a\s+glance|overview|the\s+bottom\s+line)$"`
- Pass if any match, Warn if none.
- Message pass: "Summary/TL;DR section detected." Message warn: "No TL;DR, key takeaways, or summary section found."
- Recommendation: "Add a TL;DR or 'Key Takeaways' section near the top of your content. AI search engines prefer content with upfront summaries for quick-answer extraction."

**geo-query-snippet:** Featured snippet formatting — concise answer blocks.
- Find question headings (same as qa-patterns detection above), then check if the next sibling paragraph has 40-60 words.
- Simpler approach: find all `<p>` elements, count words, check if any fall in 40-60 word range AND are preceded by a heading.
- Even simpler (robust): Select all heading+paragraph pairs. For each heading followed by a `<p>`, count words in the paragraph. If any are 40-60 words, pass.
- Pass if at least 1 snippet-formatted block found, Warn if none.
- Message pass: "Featured snippet-formatted content found (concise answer blocks)." Message warn: "No featured snippet-formatted content detected."
- Recommendation: "Follow question headings with concise 40-60 word answer paragraphs. This format matches featured snippet extraction patterns used by AI search engines."

**geo-query-faq:** Dedicated FAQ section detection (with or without schema). Per D-12.
- Check headings for FAQ patterns: regex `r"(?i)^(faq|faqs|frequently\s+asked\s+questions)$"`
- Also check if FAQPage JSON-LD schema exists (parse JSON-LD blocks, check types).
- Pass if FAQ heading or FAQPage schema found, Warn if neither.
- Message pass: "FAQ section detected." Message warn: "No FAQ section found."
- Recommendation: "Add a dedicated FAQ section with a clear heading ('FAQ' or 'Frequently Asked Questions'). FAQ sections are high-value targets for AI search citation."

Helper to find HowTo object in JSON-LD (may be top-level or in @graph):
```rust
fn find_howto_object(val: &Value) -> Option<&Value> {
    if val.get("@type").and_then(|t| t.as_str()) == Some("HowTo") {
        return Some(val);
    }
    if let Some(Value::Array(arr)) = val.get("@type") {
        if arr.iter().any(|t| t.as_str() == Some("HowTo")) {
            return Some(val);
        }
    }
    if let Some(Value::Array(graph)) = val.get("@graph") {
        for item in graph {
            if let Some(found) = find_howto_object(item) {
                return Some(found);
            }
        }
    }
    None
}
```
