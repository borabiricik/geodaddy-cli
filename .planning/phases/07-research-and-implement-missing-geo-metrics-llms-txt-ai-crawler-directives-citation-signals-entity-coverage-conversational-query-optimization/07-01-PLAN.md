Create `src/analyzers/geo_directives.rs` with two public functions:

1. `pub fn analyze_ai_meta_directives(html: &Html) -> AnalysisResult`
   - Select all `meta[name="robots"]` elements using scraper CSS selector
   - For each, get `content` attribute, convert to lowercase
   - Check for AI-specific directives: "noai", "noimageai", "nosnippet"
   - If none found: `Status::Pass`, check="geo-ai-meta-directives", message="No AI-blocking meta robot directives found. AI crawlers can process this page."
   - If found: `Status::Warn`, message=format!("AI-blocking meta directives detected: {}. These may prevent AI systems from using your content in search results.", directives.join(", ")), recommendation="Review your meta robots directives. If you want AI search visibility, remove noai/noimageai directives. If intentional, this is expected."

2. `pub fn analyze_ai_header_directives(headers: &reqwest::header::HeaderMap) -> AnalysisResult`
   - Get "x-robots-tag" header value (case-insensitive header name handled by reqwest)
   - Convert value to lowercase, check for "noai", "noimageai", "nosnippet"
   - If none found: `Status::Pass`, check="geo-ai-header-directives", message="No AI-blocking X-Robots-Tag headers found."
   - If found: `Status::Warn`, message=format!("AI-blocking X-Robots-Tag directives detected: {}.", directives.join(", ")), recommendation="Review your X-Robots-Tag HTTP headers. noai/noimageai directives may prevent AI search engines from including your content in results."
