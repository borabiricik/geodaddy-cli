**mcp/src/install.ts:**

This script runs as `node dist/install.js` during npm postinstall. It downloads the platform-appropriate geodaddy binary from GitHub releases.

Constants at top of file:
```typescript
const REPO = "borabiricik/geodaddy-cli";
const VERSION = "v0.1.1";
```

**`getPlatformTarget()` function** returns the Rust target triple:
```typescript
const map: Record<string, string> = {
  "darwin-x64": "x86_64-apple-darwin",
  "darwin-arm64": "aarch64-apple-darwin",
  "linux-x64": "x86_64-unknown-linux-musl",
  "linux-arm64": "aarch64-unknown-linux-musl",
  "win32-x64": "x86_64-pc-windows-msvc",
};
const key = `${process.platform}-${process.arch}`;
const target = map[key];
if (!target) throw new Error(`Unsupported platform: ${key}. Supported: ${Object.keys(map).join(", ")}`);
return target;
```

**`getArchiveUrl(target: string)` function:**
- For windows (`target.includes("windows")`): return `https://github.com/${REPO}/releases/download/${VERSION}/geodaddy-${VERSION}-${target}.zip`
- Otherwise: return `https://github.com/${REPO}/releases/download/${VERSION}/geodaddy-${VERSION}-${target}.tar.gz`

**`download(url: string, dest: string)` function:**
- Use Node.js built-in `https` (import from `node:https`) and `http` (import from `node:http`) for fetching
- Handle 301/302 redirects (GitHub releases redirect to S3). Follow up to 5 redirects.
- Pipe response to a `createWriteStream(dest)` using `pipeline` from `node:stream/promises`
- On non-200/non-3xx status, throw error with status code

**`extractBinary(archivePath: string, binDir: string, isWindows: boolean)` function:**
- For tar.gz (unix): use `execSync("tar -xzf " + archivePath + " -C " + binDir)` from `node:child_process`
- For zip (windows): use `execSync("powershell -command \"Expand-Archive -Path '" + archivePath + "' -DestinationPath '" + binDir + "' -Force\"")`
- After extraction, delete the archive file

**`main()` async function:**
1. Determine `binDir` = `resolve(dirname(fileURLToPath(import.meta.url)), "..", "bin")`
2. Create binDir with `mkdirSync(binDir, { recursive: true })` from `node:fs`
3. Check if binary already exists at expected path. If yes, print to stderr "geodaddy binary already exists, skipping download" and return.
4. Get platform target via `getPlatformTarget()`
5. Get archive URL via `getArchiveUrl(target)`
6. Print to stderr: `Downloading geodaddy ${VERSION} for ${target}...`
7. Download archive to `resolve(binDir, "geodaddy-archive" + (isWindows ? ".zip" : ".tar.gz"))`
8. Extract binary to binDir
9. On unix: `chmodSync(resolve(binDir, "geodaddy"), 0o755)` from `node:fs`
10. Print to stderr: `geodaddy ${VERSION} installed successfully`

All output via `console.error()` (NOT console.log -- even though this isn't the MCP server, keep the convention).

Wrap `main()` in try/catch. On error: print to stderr `"Warning: Failed to download geodaddy binary: " + error.message` and `"You can build from source with: cargo build --release"`. Exit with code 0 (not 1) so npm install doesn't fail if download fails (per Pitfall 2 from research -- graceful degradation).

Call `main()` at bottom of file.

**Update mcp/package.json** -- add postinstall script:
Change the scripts section to:
```json
"scripts": {
  "build": "tsc",
  "prepare": "npm run build",
  "postinstall": "node dist/install.js || true",
  "test": "vitest run"
}
```

The `|| true` ensures npm install doesn't fail even if the script errors (belt + suspenders with the try/catch).
