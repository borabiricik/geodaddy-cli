```rust
use serde::Serialize;

#[derive(Serialize, Debug, Clone, PartialEq)]
#[serde(rename_all = "lowercase")]
pub enum Status { Pass, Fail, Warn }

#[derive(Serialize, Debug, Clone)]
pub struct AnalysisResult {
    pub check: &'static str,
    pub status: Status,
    pub message: String,
    pub recommendation: String,
}

#[derive(Serialize, Debug)]
pub struct CategoryScores {
    pub technical: f64,
    pub content: f64,
}

pub fn calculate_score(results: &[AnalysisResult]) -> (f64, CategoryScores);
```

Severity point values (canonical — D-06):
- critical = 10 points
- warning = 5 points
- info = 2 points

Fail = full loss, Warn = half loss, Pass = 0 loss.
Score = (earned / max_possible) * 100, clamped to [0, 100].
Overall = (technical + content) / 2.

Check-to-severity mapping (canonical — D-06):
| check prefix       | severity |
|--------------------|----------|

Create `cli/src/scoring.rs` with the following exact contents:

1. `Status` enum:
   - Variants: `Pass`, `Fail`, `Warn`
   - Derives: `Serialize, Debug, Clone, PartialEq`
   - `#[serde(rename_all = "lowercase")]` so it serializes as lowercase strings

2. `AnalysisResult` struct:
   - `pub check: &'static str`
   - `pub status: Status`
   - `pub message: String`
   - `pub recommendation: String`
   - Derives: `Serialize, Debug, Clone`

3. `CategoryScores` struct:
   - `pub technical: f64`
   - `pub content: f64`
   - Derives: `Serialize, Debug`

4. `severity_points(check: &str) -> u32` private helper:
   Uses a match on check ID string to return point values per D-06 canonical table:
   - `"tech-meta-title"` | `"tech-heading-h1"` | `"tech-mobile-viewport"` | `"tech-https"` | `"cont-json-ld"` => 10 (critical)
   - `"tech-broken-links"` | `"tech-redirect-chains"` | `"tech-meta-description"` | `"tech-heading-hierarchy"` | `"tech-robots-txt"` | `"cont-heading-structure"` | `"cont-alt-text"` => 5 (warning)
   - `"tech-sitemap-xml"` | `"cont-semantic-html"` => 2 (info)
   - `_` => 5 (default to warning for unknown checks — fail safe)

5. `pub fn calculate_score(results: &[AnalysisResult]) -> (f64, CategoryScores)`:
   - Separate accumulators for tech and content: `(earned, max)` pairs
   - Iterate over results, call `severity_points(result.check)` to get `pts`
   - Match `result.status`:
     - `Status::Pass` => add pts to earned, pts to max (full points earned)
     - `Status::Fail` => add 0 to earned, pts to max (full points lost)
     - `Status::Warn` => add pts/2 to earned (integer division), pts to max (half points lost)
   - Route to technical bucket if check starts with "tech-", content bucket if "cont-"
   - Compute category scores: if max == 0, score = 100.0, else (earned as f64 / max as f64) * 100.0
   - Overall score = (tech_score + content_score) / 2.0
   - Clamp all scores to [0.0, 100.0] via f64::clamp
   - Return (overall, CategoryScores { technical: tech_score, content: content_score })
