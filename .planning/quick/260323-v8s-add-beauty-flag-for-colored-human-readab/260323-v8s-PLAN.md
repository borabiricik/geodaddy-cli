<task type="auto">
  <name>Task 1: Add `colored` dependency and create src/beauty.rs renderer</name>
  <files>Cargo.toml, src/beauty.rs</files>
  <action>
    1. Add to Cargo.toml under [dependencies]:
       `colored = "2"`

    2. Create src/beauty.rs with a single public function `print_beauty_report`.
       The function signature must accept Report and PageResult by reference — since
       these structs are defined in main.rs, beauty.rs will use `super::` to reference them,
       OR the function accepts the data as primitive slices (see below for chosen approach).

       Chosen approach: accept `&Report` directly via `pub(crate) fn print_beauty_report(report: &Report)`.
       This requires Report and PageResult to be `pub(crate)` in main.rs (done in Task 2).

    3. Implement print_beauty_report to render:

       HEADER:
       ```
       geodaddy — GEO Analysis Report
       URL: <url>
       Crawled: <crawled_at>
       ─────────────────────────────────
       ```
       Print the header lines in bold/white using `.bold()`.

       AGGREGATE SCORE BLOCK (printed before pages):
       Color the score using score_color(score): green >=80, yellow >=50, red <50.
       ```
       Overall Score: <score:.1>/100   [colored by score]
       Technical: <n:.1>  Content: <n:.1>  GEO: <n:.1>  Performance: <n:.1 or N/A>
       ```

       PER-PAGE SECTION (iterate report.pages):
       For each page, print:
       ```
       ━━━ Page N/total: <url> ━━━
       Score: <score:.1>/100
       [if robots_blocked: print "(robots blocked)" in yellow]

       Technical: <n:.1>  Content: <n:.1>  GEO: <n:.1>  Performance: <n:.1 or N/A>

       CHECK RESULTS (iterate results):
         [PASS] check-id  message         (green)
         [WARN] check-id  message         (yellow)
         [FAIL] check-id  message         (red)
             -> recommendation text       (dimmed, only for Warn/Fail)
       ```

    4. Helper fn score_color(score: f64) -> colored::Color:
       - score >= 80.0 => Color::Green
       - score >= 50.0 => Color::Yellow
       - _ => Color::Red

    5. Use `use colored::Colorize;` at top of beauty.rs.
       Use `.green()`, `.yellow()`, `.red()`, `.bold()`, `.dimmed()` on string literals and
       format! output converted to String before calling color methods.

    6. For Performance display: `match categories.performance { Some(p) => format!("{:.1}", p), None => "N/A".to_string() }`.

    7. No external I/O — print_beauty_report writes to stdout via `println!()`.
